One agent is the master. I ask it to manage the child [Herdr](https://herdr.dev) worktrees: prompt them, check progress, and pull in more agents to review and merge. Each worktree can run any coding agent.

I can spawn 50 sessions across Pi, Claude, Grok, OpenCode, and Devin. Some plan, some implement, some review PRs. They talk by Herdr sending a prompt into the other session, and they stay busy day and night. That is the tokenmaxxing.

Write skills so the master knows which agent is best for which task.

[herdr-desk](https://github.com/duyet/herdr-desk) wakes on a schedule for the boring automated work: GitHub issue triage, code review, a summary, then a report to me on Telegram.

This is also how I work across repos. One project is wired into another. An agent in the first raises an issue, an agent in the second fixes it, and both keep improving.

You can run Herdr on multiple machines and still have one dashboard, even on your phone. Install Tailscale on all of them.

If you use Grok Bot, Cue, Muse, or Dot, install Tailscale and Herdr on their computer too. They can drive the sessions, and from your Mac you can see what is actually running.

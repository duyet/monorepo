It's been a year and I'm saying this seriously now: I don't read code anymore.

You can debate me about how badly I ship, but soon you'll realize and admit I was right.

I retired from Professional Software Engineer. I'm now just the one who makes agents make programs.

A year ago this was a joke. I wrote [that I never looked at the code](/2026/06/coding-agent-2026/) after handing Claude Code an overnight refactor, and people laughed. Then I shipped [AnyRouter](/2026/07/anyrouter/) without knowing what's behind the UI, trusting thousands of smoke tests instead. Then [duyetbot](/2026/08/grok-bot/) took over the repos entirely — issues, PRs, deploys, validation.

Now it's just how I work. I write the docs, the specs, the GitHub issues. Agents write the code, review the code, fix the code, deploy the code. I review screenshots, videos, and behavior. If it works for a real user, it ships. If it doesn't, I paste a screenshot and tell the bot to try again.

Do I miss reading code? Sometimes. The way you miss compiling kernels for fun. Nostalgia, not productivity.

The funny part: I ship more than ever, and the quality is fine. Not perfect. Neither was mine.

But the future of making software has never been brighter. You don't need permission from a compiler anymore. You just need to describe what you want clearly enough that an agent can build it, test it, and prove it works.

I don't read code anymore. I read results.
